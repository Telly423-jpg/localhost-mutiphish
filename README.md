# localhost-mutiphish
This repo hosts localhost-run scripts, with _cn files for Chinese UI and _en for English. Core logic is in private hidden modules not included here, so public scripts only call those hidden parts and cannot be modified by others.

本仓库存放本地运行的脚本，文件名带_cn的是中文界面版，带_en的是英文界面版。核心逻辑放在未随仓库上传的私有隐藏模块中，公开脚本仅调用这些隐藏模块，他人无法查看和修改核心部分。
